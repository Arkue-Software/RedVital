# Migraciones

Las migraciones de base de datos se mantienen en el repositorio
[Arkue-Software/databases](https://github.com/Arkue-Software/databases), no en
esta carpeta historica. Consulta su README para el estado por servicio, las
reglas de Flyway y el entorno local. Las migraciones ya aplicadas no se editan;
los cambios se agregan en versiones nuevas.
